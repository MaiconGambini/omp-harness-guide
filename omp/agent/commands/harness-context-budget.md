name: harness-context-budget
description: "Report the context/tooling budget for skills, plugins, commands, and MCPs; recommend lazy-loading."
---

Run `node ~/.omp/agent/scripts/harness-context-budget.mjs` from the current repo. Summarize the largest skills, commands, and MCP surfaces contributing to the always-loaded context budget, and recommend which to lazy-load or trim. Reference `skill://harness-context-budget` for the interpretation guidance. Do not print secret values.
